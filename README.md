# alawai
Evaluating instrumentation-based proxies for wastewater pollution

The code and data here are connected to the 4th chapter of my dissertation, The island mass effect, nearshore circulation, and coastal pollution in Hawai’i, Published at University of Hawaiʻi at Mānoa. Link will be available when graduate division posts it.

Also associated with the following manuscript in review:
“Towards real-time wastewater pollution tracking: Evaluating the performance of instrumentation-based wastewater pollution proxies in an urban estuary”
